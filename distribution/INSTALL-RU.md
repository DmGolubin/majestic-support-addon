# SupportTemplates: два варианта для Windows

Выберите один вариант для каждого клиента Discord: **SupportTemplates Lite**
или **SupportTemplates для BetterDiscord**. Не устанавливайте оба варианта
одновременно в один клиент.

**Изменение в выпуске с автоматической диагностикой:** локальная запись
включена по умолчанию и не отключается по сроку.
Её можно сразу выключить в настройках, в разделе «Логи» под «Быстрым вводом».
Файл сохраняется автоматически на вашем компьютере; автоматической отправки нет.

## 1. SupportTemplates Lite

Lite — сборка на основе Vencord, содержащая только пользовательский плагин
SupportTemplates и необходимые внутренние модули.

1. Распакуйте `SupportTemplates-standalone-<версия>.zip` целиком в обычную папку.
   Не запускайте BAT внутри ZIP. Слово `standalone` в имени файла обозначает Lite.
2. Полностью закройте выбранный Discord, включая трей.
3. Запустите `status.bat`, затем `install.bat`. Установщик предлагает выбрать
   найденный Discord (Stable) или Discord Canary. Канала по умолчанию нет;
   Enter или `0` отменяет действие.
4. Запустите выбранный Discord. Настройки доступны из окна шаблонов и раздела
   SupportTemplates.

Для явного выбора канала используйте `install.bat -Channel Stable` или
`install.bat -Channel Canary`. Выбор клиента реализуется установщиком Lite;
точные параметры вашей версии описаны в README внутри пакета.

## 2. SupportTemplates для BetterDiscord

Для уже установленного BetterDiscord положите `SupportTemplates.plugin.js` в папку
плагинов BetterDiscord (её можно открыть из настроек плагинов), затем включите
SupportTemplates. Настройки доступны через шестерёнку плагина.
Сам BetterDiscord в этот файл не входит.

При ручном обновлении замените файл, оставив в plugins только один SupportTemplates.
После первого входа сессия сохраняется с шифрованием в профиле Discord.
Кнопка выхода удаляет её. Очистка данных профиля потребует повторного входа.
Обновления загружаются автоматически и включаются после Ctrl+R или следующего
запуска. Плагин не перезагружает редактор и не заменяет наблюдаемый BD файл.

## Версия и обновления

В интерфейсе Lite называется **SupportTemplates Lite**, а плагин BetterDiscord —
**SupportTemplates**. Оба варианта используют общий интерфейс и ядро.
Суффикс `canary` в технической версии означает тестовый выпуск SupportTemplates,
а не требование установить Discord Canary.

Источник обновлений — GitHub Releases репозитория `skyjacc/support-templates`.
В обоих вариантах проверка выполняется при запуске и периодически во время работы.
Автоматическая загрузка доступна для опубликованных выпусков публичного репозитория;
вход в GitHub и токены сотрудников не требуются.

Обновление скачивается с проверкой версии, варианта пакета, размера и SHA-256.
Обновлятор не закрывает Discord и не перезагружает редактор с черновиком.
Совместимые изменения интерфейса вступают в силу после Ctrl+R; изменения
загрузчика и native-кода Lite требуют полного выхода через трей и нового запуска.
Пакеты canary получают только выпуски canary.

Сначала сохраните черновики. При проблемах с установкой Lite используйте
`status.bat`, `repair.bat` или `uninstall.bat` согласно README пакета.
Настройки не нужно удалять.

## Автоматическая локальная диагностика

Запись включена по умолчанию без автоматического срока отключения. Отключение
сохраняется после Ctrl+R и перезапуска; убрать или изменить функцию можно будущим
обновлением. Раздел «Диагностика» расположен ниже «Быстрого ввода».

`main.log` — дописываемый текстовый журнал. Каждая строка
начинается с местной даты и времени, например `[20.10.2026 13:45:34]`.
Перезапуск и обновление не обнуляют историю. Файлы ротируются по 10 МиБ:
текущий и девять архивов, суммарно около 100 МиБ. При достижении лимита удаляется
самый старый архив. Ограничение 2000 событий относится только к буферу интерфейса,
а не ко всей истории в файлах. При разборе давней проблемы приложите и архивы.

Журнал содержит состояние плагина, обезличенные действия, геометрию и измерения
производительности, попытки и результаты запросов API, обновления сессии,
причины повторного подключения и события воспроизведения звука.
Для разбора звука сохраняются технические ID тикета, канала и сервера,
тип события, проверки назначения/свежести, причины пропуска и применённые
настройки. Успешный запуск аудио не доказывает слышимость на устройстве.
Тексты сообщений, шаблонов, значения полей, токены, заголовки и тела запросов
или ответов не записываются. Автоматической отправки нет: файл передаётся вручную.
Последние несколько секунд могут потеряться при аварийном завершении процесса.

В Lite журнал находится в каталоге диагностики внутри данных соответствующего
профиля. В BetterDiscord — в папке профиля SupportTemplates рядом с папкой plugins,
а не среди плагинов. Кнопка **«Открыть папку логов»** в настройках открывает
каталог текущего профиля; копировать длинный путь вручную не требуется.
Если автоматическое сохранение недоступно, проверьте сообщение об ошибке в этом разделе.
Передавать `main.log` и нужные архивы разработчику нужно самостоятельно.
Старые журналы предыдущих выпусков сохраняются при переходе на новое имя.
Лимит 100 МиБ относится к серии `main.log`; сохранённые старые файлы в него не входят.

Если обновление добавляет или меняет native-компонент записи файла в Lite,
нужны полный пакет и полный выход из Discord через трей с последующим запуском.
Одного Ctrl+R для такого обновления недостаточно. Для совместимых изменений
только интерфейса действует описанный в пакете режим Ctrl+R; BetterDiscord
активирует обновлённый плагин при следующей загрузке его runtime.

## Проверка после установки

- Нажмите шаблон: текст должен появиться в поле сообщения без отправки.
- Проверьте вход, создание и сохранение личного шаблона.
- Проверьте вставку в основной чат и боковую панель, звук и открытие настроек.
- После Ctrl+R и полного перезапуска проверьте восстановление входа.

Автоматические тесты не заменяют проверку в настоящем Discord.
Lite и BetterDiscord проходят отдельную приёмку, включая обновление и удаление.

## Настройки тикетов

Новые тикеты и личные напоминания настраиваются отдельно. Для каждого сервера
можно выбрать собственный звук, громкость и включение. Настройки хранятся
на этом компьютере. Общий переключатель «Напоминать в Discord» действует
на все личные напоминания; порог ожидания меняется в Telegram.

В тестовом выпуске кнопка «Показать уведомление» во вкладке «Тикеты»
показывает локальный пример уведомления. Тикет не создаётся.

Личные шаблоны доступны в обоих проектах, к которым подключён ваш аккаунт.
Ищите их во вкладке «Мои»; показ во «Все» зависит от настройки личных шаблонов.
