# SupportTemplates: три варианта для Windows

Выберите один вариант для каждого клиента Discord. Не устанавливайте BetterDiscord,
полный Vencord и отдельную сборку одновременно в один клиент.

## 1. BetterDiscord

Для уже установленного BetterDiscord: положите `SupportTemplates.plugin.js` в папку
плагинов BetterDiscord (её можно открыть из настроек плагинов), затем включите
SupportTemplates. Настройки доступны через шестерёнку плагина.
Сам BetterDiscord в этот файл не входит.
Используйте исправленный BD-плагин `.15` или новее. В стандартном BetterDiscord
вход действует до перезапуска; для обновления замените файл плагина вручную.
Ограниченный загрузчик BD не предоставляет функции, нужные нашему защищённому
хранилищу входа и файловому автообновлятору. Настройки показывают эти ограничения.

## 2. Полный Vencord с SupportTemplates

Распакуйте `SupportTemplates-vencord-<версия>.zip` целиком. Это собственная сборка
Vencord с его обычными плагинами и SupportTemplates. Прочитайте README внутри,
закройте целевой Discord через трей, затем запустите `install.bat`.
Не запускайте установщик внутри ZIP. EXE-установщик не требуется.

## 3. Отдельная сборка SupportTemplates

Распакуйте `SupportTemplates-standalone-<версия>.zip` целиком. Внутри только наш
пользовательский плагин и необходимые внутренние модули Vencord.
Закройте целевой Discord через трей, запустите `install.bat`, затем Discord.
По умолчанию выбран Canary; параметры Stable описаны в README пакета.
Настройки доступны из окна шаблонов и раздела SupportTemplates.

## Обновления

Источник — GitHub Releases репозитория `skyjacc/support-templates`.
В вариантах Vencord проверка выполняется при запуске и периодически во время работы.
Пока репозиторий приватный или выпуск не опубликован, автоматическая загрузка
недоступна; вход в GitHub и токены сотрудников не требуются.

Обновление скачивается с проверкой версии, варианта пакета, размера и SHA-256.
Обновлятор не закрывает Discord и не перезагружает редактор с черновиком.
Совместимые изменения интерфейса вступают в силу после Ctrl+R; изменения
загрузчика и native-кода требуют полного выхода через трей и нового запуска.
Для полного Vencord выпускается обновление всей нашей сборки, чтобы сохранить
SupportTemplates. Пакеты canary получают только выпуски canary.

Сначала сохраните черновики. При проблемах с установкой используйте инструкции
status/repair/uninstall внутри выбранного пакета. Настройки не нужно удалять.

## Статус проверки

Локальная сборка и автоматические тесты не заменяют проверку в настоящем Discord.
BetterDiscord, полный Vencord и отдельная сборка принимаются отдельно: вход,
создание/сохранение, вставка в основной чат и боковую панель, звук, Ctrl+R,
полный перезапуск, обновление и удаление. Публикация этого пакета не выполняется
автоматически командой сборки.
