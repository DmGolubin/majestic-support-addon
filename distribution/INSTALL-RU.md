# Установка SupportTemplates

Выберите **один вариант** для каждого клиента Discord. Поддерживаются Windows, Discord Stable и Discord Canary.

## BetterDiscord

1. Скачайте `SupportTemplates.plugin.js` из релиза.
2. В BetterDiscord откройте **Настройки → Плагины → Открыть папку плагинов**.
3. Положите туда скачанный файл и включите SupportTemplates.
4. Откройте плагин и войдите через панель.

BetterDiscord устанавливается отдельно. При обновлении замените файл плагина; настройки удалять не нужно.

## Lite + SupportTemplates

1. Скачайте `SupportTemplates-standalone-<версия>.zip` и полностью распакуйте его.
2. Полностью закройте выбранный Discord, включая значок в трее.
3. Запустите `install.bat`. В консольном меню выберите Discord Stable или Canary и нажмите **«Установить / обновить»**.
4. Запустите Discord и войдите в SupportTemplates через панель.

Снаружи находятся `install.bat`, `uninstall.bat` и папка `SupportTemplates/` со всеми файлами. Сохраняйте распакованную папку целиком.
Меню проверяет обновления и позволяет загрузить новую версию с проверкой SHA-256. При следующей установке используется проверенный пакет из кеша.
Установщик также умеет проверять состояние, восстанавливать подключение и удалять Lite.
Чужой Vencord или BetterDiscord автоматически не заменяется.

## Использование

Шаблон вставляется в поле сообщения без отправки. Личные шаблоны доступны во вкладке «Мои».
Во вкладке «Тикеты» отдельно настраиваются звук новых тикетов и личные напоминания для Majestic и России Онлайн.
Новые тикеты дают только звук. Личные напоминания показывают карточку сервера с переходом в назначенный тикет, когда API передаёт доступный Discord-канал.
Порог ожидания приходит из панели; отдельная настройка минут Discord ожидает API.

## Обновления

Версия отображается как **SupportTemplates · Версия 1.0.2**.
Номер версии плагина не зависит от выбранного клиента Discord.

После первого релиза обновления публикуются после PR и проверки Дмитрия.
Плагин проверяет опубликованные выпуски при запуске и примерно раз в шесть часов.
Для анонимных автообновлений репозиторий должен быть публичным. Пока он приватный, участники скачивают файлы вручную из Releases.

Пакеты проверяются по версии, размеру и SHA-256. Discord не закрывается принудительно.
В BetterDiscord обновление активируется при следующей загрузке плагина; для Lite полностью выйдите из Discord через трей и запустите его снова после установки.
Для перехода с прежних тестовых `canary.*` на 1.0.1 установите соответствующий пакет вручную: это разные каналы обновления.

## Логи

В настройках откройте **«Логи» → «Открыть папку логов»**. Файл `main.log` записывается автоматически и сохраняется между запусками.
Запись можно отключить. Тексты сообщений, шаблонов и токены в журнал не попадают; автоматической отправки нет.
Для сообщения об ошибке передайте разработчику `main.log` и, при необходимости, архивы из той же папки.

Для перехода с Lite 1.0.1 на компактный архив скачайте новый пакет один раз вручную. В следующих версиях используйте проверку обновлений в BAT.
