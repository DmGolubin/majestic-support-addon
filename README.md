# SupportTemplates

Шаблоны ответов поддержки Majestic RP и Россия Онлайн в Discord, в стиле панели Majestic.
Версия `0.1.0-canary.14` подготовлена в трёх вариантах для Windows: BetterDiscord,
полный Vencord с SupportTemplates и отдельная сборка на основе Vencord только с нашим плагином.
Вход, FAQ и личные шаблоны работают через API панели; доступ определяется аккаунтом.

Для BetterDiscord используйте `.16`: [выпуск](https://github.com/skyjacc/support-templates/releases/tag/v0.1.0-canary.16).
Вход сохраняется с шифрованием в профиле Discord, обновления скачиваются автоматически
и включаются после Ctrl+R или нового запуска. Для перехода с `.15` файл нужно заменить один раз.
Полный Vencord и отдельная сборка остаются в выпуске `.14`.

## Установка и обновления

[Скачать выпуск .14](https://github.com/skyjacc/support-templates/releases/tag/v0.1.0-canary.14)
· [Инструкция установки](distribution/INSTALL-RU.md)
· [Сборка и публикация](distribution/README.md).

Для BetterDiscord используется файл `SupportTemplates.plugin.js`. Два варианта
на основе Vencord поставляются в ZIP с BAT/PowerShell-установщиком, без EXE.
Выберите один вариант для каждого клиента Discord.

Обновлятор проверяет GitHub при запуске и примерно каждые шесть часов, проверяет
размер и SHA-256 пакета и готовит обновление к следующему запуску. Он не закрывает
Discord принудительно. Пока репозиторий приватный, анонимные автообновления
недоступны; пакеты скачивает пользователь с доступом к репозиторию.

Это тестовый выпуск Canary. Отдельная `.14` установлена в Canary владельца;
живая приёмка интерфейса и проверка остальных двух вариантов в реальных клиентах
остаются открыты. [Проверки пакетов](docs/audits/2026-10-19-three-distributions.md).

## Где что

### Отдельная сборка и BAT

[Инструкция отдельной сборки](standalone/README.md). Сборка: `pnpm build:standalone`; проверки установщика на временных файловых стендах Windows: `pnpm test:installer`. По умолчанию установщик выбирает Canary. Полная установка требует выхода из целевого Discord через трей. Для совместимого ручного обновления интерфейса есть `UpdateRenderer`; после него достаточно Ctrl+R. Обновления загрузчика и нативной части требуют полного перезапуска.

### Личные шаблоны и настройки

Откройте настройки шестерёнкой рядом с поиском. В «Мои шаблоны» можно создавать, редактировать, копировать и удалять личные ответы, выбирать цвет, проект, папку и команду. В редакторе доступны «Поле для заполнения» и «Приветствие». Шаблоны доступны в обычном поиске и подсказках по команде.

Папки можно создавать, переименовывать и удалять. Удаление папки сохраняет её шаблоны без папки. Основные FAQ доступны для чтения, редактируются на сайте.

Личные шаблоны сохраняются в аккаунте панели. Избранное, бинды и история использования остаются локальными. Плагин вставляет подготовленный текст в редактор Discord; отправляет его сотрудник.

Во вкладке «Настройки» доступны подключение, префикс команд, предпросмотр и список разрешённых серверов. В «Тикеты» настраиваются уведомления и свой звук. Порог личного напоминания задаётся в Telegram; доступность функции зависит от API панели.

## Серверы

Плагин работает только на трёх серверах (таблица в `src/core/guard.ts`, `serverMode`):

| Сервер | id | Режим |
|---|---|---|
| Majestic RP | `530693013622489088` | `mj` — шаблоны Majestic и общие; чужой проект — парный шаблон или предупреждение |
| Россия Онлайн | `1089530150540034181` | `ro` — то же для РО |
| Tech™ (сервер саппортов) | `1395915167040016545` | `all` — переключатель «Majestic / Россия Онлайн» в окне (запоминается): список, Alt+1…9, бинды и подсказки `;` — выбранного проекта и общие; без предупреждений о чужом проекте |

На остальных серверах и в ЛС (`off`) плагин невидим: кнопки нет, Ctrl+Alt+T, Alt+1…9, бинды и `;команда`
не перехватываются — клавиши уходят в Discord. Режим отладки работает везде и показывает режим сервера.

## Разработка

```bash
pnpm install
pnpm test            # ядро (Vitest)
pnpm typecheck
pnpm icons           # перегенерировать src/vencord/ui/icons.ts из assets/
pnpm sync:vencord    # скопировать плагин в C:/Users/oblako/dev/Vencord/src/userplugins/supportTemplates
cd C:/Users/oblako/dev/Vencord && pnpm build   # затем Ctrl+R в Discord
```

`VENCORD_DIR` переопределяет путь к Vencord. Vencord должен быть установлен из исходников (`pnpm inject`).

## Шрифты

Окно использует шрифты панели: Golos Text и JetBrains Mono (SIL Open Font License 1.1, тексты лицензий — `assets/fonts/OFL-*.txt`). Они встроены в плагин (`pnpm fonts` → `src/vencord/ui/fontData.ts`) и подгружаются из памяти под именами «STX Golos» / «STX Mono»: без сетевых запросов, шрифты самого Discord не меняются.
