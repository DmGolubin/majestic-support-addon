| Вариант | Установка |
|---|---|
| **SupportTemplates** | Скачайте ZIP из [релиза](https://github.com/DmGolubin/majestic-support-addon/releases/latest), распакуйте целиком и запустите `install.bat`. Выберите «Установить», затем нужный Discord. |
| **BetterDiscord** | Скачайте [SupportTemplates.plugin.js](https://github.com/DmGolubin/majestic-support-addon/releases/latest/download/SupportTemplates.plugin.js), положите в папку плагинов BetterDiscord и включите. |

Установщик сам проверяет обновления. Для удаления SupportTemplates запустите `uninstall.bat`.
