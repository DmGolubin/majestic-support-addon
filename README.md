# SupportTemplates

Шаблоны ответов и личные напоминания для поддержки Majestic RP и России Онлайн в Discord.

## Скачать

**[Открыть последний релиз и выбрать вариант установки](https://github.com/DmGolubin/majestic-support-addon/releases/latest)**

| Вариант | Что скачать | Кому подходит |
|---|---|---|
| **BetterDiscord** | `SupportTemplates.plugin.js` | BetterDiscord уже установлен |
| **Lite + SupportTemplates** | `SupportTemplates-standalone-1.0.1.zip` | Нужна отдельная сборка с графическим установщиком |

Версия первого выпуска — **1.0.1**. Оба варианта поддерживают Discord Stable и Discord Canary на Windows.
В архиве Lite сборка находится в `payload/`, а GUI-установщик запускается через `install.bat` рядом с ней.

[Инструкция установки](distribution/INSTALL-RU.md)

## Возможности

- Поиск по названию и содержимому шаблонов, с учётом опечаток и транслита.
- Общие FAQ панели и личные шаблоны, доступные в обоих проектах аккаунта.
- Вставка ответа в редактор Discord. Сообщение отправляет сотрудник.
- Звук новых тикетов с отдельными настройками Majestic и России Онлайн.
- Личные напоминания с карточкой сервера и переходом в доступный назначенный тикет.
- Локальный `main.log`, открываемый из настроек плагина.

Для входа необходим доступ к панели. Плагин работает на серверах Majestic RP, России Онлайн и Tech.

## Обновления

Первый выпуск публикуется напрямую. **Будущие обновления после релиза проходят PR и проверку Дмитрия**, затем публикуется новая версия. Пуш исходников сам по себе не выпускает обновление.

Обновлятор получает опубликованные пакеты из GitHub Releases, проверяет версию и SHA-256.
Пока репозиторий приватный, скачивание доступно участникам репозитория, а анонимные автообновления недоступны.

## Разработка

Общее ядро находится в `src/core/`, интерфейс — в `src/vencord/`.
Адаптер BetterDiscord — `betterdiscord/`, сборка Lite и установщик — `standalone/`.
Версия задаётся в `distribution/config.json`.

```sh
pnpm install --frozen-lockfile
npm ci --prefix betterdiscord
pnpm test
pnpm typecheck
pnpm typecheck:vencord
```
