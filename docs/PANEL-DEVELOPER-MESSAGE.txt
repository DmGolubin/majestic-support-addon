Привет! Для SupportTemplates нужна интеграция с панелью. Сам плагин и его интерфейс делаю я; от тебя нужна серверная часть:

1. Вход через панель: пользователь нажимает «Подключить», на сайте подтверждает устройство («Разрешить / Отказать»), плагин получает отдельный токен. Нужны продление и отзыв устройства.
2. API чтения основных FAQ с категориями, статусами и версиями. Через токен плагина менять FAQ нельзя, даже старшему: основные шаблоны редактируем на сайте.
3. API личных шаблонов и папок: создание, редактирование текста/цвета/команды, удаление и восстановление. Пользователь работает только со своими записями; сайт и плагин используют одну библиотеку.
4. Доставка обновлений: предлагаю сигнал SSE после изменения + резервную проверку раз в минуту. Перед вставкой проверяем свежесть, если прошло больше 30 секунд. Интервалы и поведение без сети нужно согласовать.
5. Стабильные ID, версии и контроль конфликтов, чтобы одновременные правки не затирали текст, а повтор запроса не создавал дубликаты.

Полное ТЗ приложено: PANEL-API-CONTRACT.md — схема входа, маршруты, JSON, права, ошибки и приёмка. Это предложенный контракт: если часть уже есть в API расширения, давай используем её, сохранив эти ограничения.

Для подключения с моей стороны понадобятся согласованная схема/OpenAPI, тестовое окружение и два тестовых аккаунта с разными правами. Плагин не отправляет сообщения Discord и не передаёт переписку или статистику использования шаблонов на сайт.

Также приложен локальный интерактивный макет panel-api-demo.html: можно пройти вход, отказ, обновление FAQ и конфликт версии. Он работает на тестовых данных и не подключается к панели.
