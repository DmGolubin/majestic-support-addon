# Библиотека аккаунта: редактор и интерфейс

Согласованный источник требований: замечания владельца от 18.10.2026 к трём скриншотам Canary. Это следующий этап, ещё не выполненный редизайн.

## Что установлено по коду

- `Settings.tsx` в режиме панели выводит личные шаблоны как заголовок и полный текст с ссылкой «Редактировать на панели». Компонент `PersonalLibrary` используется только без включённой панели.
- Импорт, переключатель локальной библиотеки и демо всё ещё доступны в пользовательском интерфейсе. Предыдущее пожелание убрать их не завершено.
- `panelClient.ts` запрашивает только profile:read, faq:read, personal:read, folders:read, sync:read. Существующий вход не даёт клиенту запрошенных прав записи.
- Переданный контракт `contracts/panel-2026-10-18/discord-plugin-api.md` уже описывает POST/PATCH/DELETE personal-templates и folders, восстановление из trash, personal:write/folders:write, Idempotency-Key и If-Match. Наличие контракта не заменяет живую проверку записи.
- В `TicketSettings.tsx` работает настройка звука нового тикета; личные напоминания представлены текстовой заглушкой. По текущему контракту порог напоминаний читается из Telegram, плагин меняет только discordEnabled. Нового API для изменения порога из плагина сейчас не предполагаем.

## Ближайший объём

1. **Категории в компактном меню (A12/A18).** Вместо нескольких строк мелких одинаковых кнопок — одна строка фильтров: категория с выпадающим списком и количеством, сброс выбранного фильтра. Теги показывать при наличии данных, не создавать пустые контролы. Сохранить клавиатуру, поиск и Shift-превью.
2. **Вход в управление (A18).** Убрать отдельную строку с широкой кнопкой. Небольшая SVG-кнопка настроек рядом с поиском, с tooltip и доступным именем; без пустой левой половины заголовка.
3. **Мои шаблоны (C06/A18).** Явно отделённый список карточек: цветная отметка, название, папка, короткий фрагмент. По выбору — редактор, а не все полные тексты одновременно. Создание, редактирование, удаление, цвет, папка, команда и общий для двух проектов шаблон — внутри плагина, с записью на панель. Сохранить переменные, поля, списки, даты, границу приветствия и предпросмотр. Основной FAQ доступен только для чтения.
4. **Убрать старые сценарии (A18).** Из обычного интерфейса убрать импорт файлов, локальную библиотеку, возвращение к ней и переключатель демо. Аккаунт панели — единственная рабочая библиотека. Тестовый стенд можно сохранить отдельно. Старые данные на диске не удалять молча: UI-очистка не требует их уничтожения. Q01 (предпросмотр/откат импорта) снят с актуального плана, а не помечен выполненным.
5. **Серверы (A18).** Компактные элементы с иконкой сервера и названием Majestic / Россия Онлайн / Tech. Переход открывает соответствующий сервер; показывать fallback, если иконка недоступна. Не занимать отдельный большой экран объяснениями.
6. **Структура настроек (A18).** Три раздела: «Мои шаблоны», «Настройки», «Тикеты». Подключение — компактный блок внутри настроек: аккаунт, состояние синхронизации, обновление библиотеки, выход; ошибки раскрываются по необходимости. Отдельную вкладку подключения убрать. Сохранить управление префиксом.
7. **Тикеты (B06/A18).** Отдельные компактные блоки «Новые тикеты» и «Игрок ждёт ответа». Выключатель, короткое пояснение, ограниченный по ширине регулятор громкости, тест звука и понятный интервал между сигналами. SVG, единые dropdown/checkbox с доступной клавиатурой. Не требовать от обычного саппорта ручного ввода ID: показывать проекты и разрешённые каналы по именам; техническую настройку при необходимости вынести из основного сценария. Не изображать ещё не подключённое напоминание работающим.

## Запись на панель: требования к завершению C06

- Запрашивать права записи явно через подтверждение на панели. Сохранённую сессию только для чтения распознавать и предлагать расширить доступ; не сбрасывать её молча и не считать новые права выданными автоматически.
- Создание использует один Idempotency-Key на действие и повторяет тот же запрос без дубликатов.
- Изменение/удаление передаёт серверную version через If-Match. При 412 — перечитать данные и предложить решение, не перетирать правку сайта.
- Ошибка сети или сохранения не закрывает редактор и не уничтожает черновик. Черновики связаны с аккаунтом; при отзыве доступа действует контракт очистки рабочего кэша и черновиков.
- Сообщать «Сохранено» только после успешного ответа. Изменение в плагине видно на сайте; изменение на сайте приходит обратно в плагин.
- Проверить создание/изменение/цвет/папку/удаление на собственном тестовом шаблоне. Текущие FAQ не менять.
- Закрыть Q10 в рамках защиты редактора от ухода из настроек Discord.
