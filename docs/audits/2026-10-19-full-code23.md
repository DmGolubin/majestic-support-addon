Проверен весь собственный рабочий код проекта, а не только последние изменения.
Новых функций продукта не добавлено. Исправлено **27 дефектов приложения и доставки
обновлений**, ещё **8 дефектов инструментов проверки**. Один подтверждённый риск
стороннего компонента полной сборки Vencord остаётся открытым.

Тестовые файлы отмечены отдельно: их выполнение не выдаётся за ручной аудит
каждой строки тестов. Код зависимостей, Discord и всех сторонних плагинов Vencord
не включён в заявление о полном ручном аудите собственного кода.

## Windows-хранилище: дополнительная проверка производительности

В нативном резервном пути BetterDiscord старый `spawnSync` действительно
блокировал event loop: повторное измерение дало паузы 8,9 / 3,1 / 3,4 секунды
на проверке доступности, шифровании и расшифровке, без единого срабатывания таймера.
Новый `execFile` выполняет операции асинхронно; проверка доступности запускает
один дочерний процесс вместо двух. В измерении таймеры продолжали работать
(186–241 срабатывание за операцию, максимальные наблюдавшиеся интервалы 29–45 мс).

Это устранение блокировки интерфейса, а не обещание мгновенного шифрования:
сами операции всё ещё заняли 3–4 секунды на данной машине. Проверены настоящий
Windows CurrentUser DPAPI и синтетические данные в памяти, не пользовательский
аккаунт Discord. Формат, entropy, шифрование, границы ввода/вывода, очередь
сохранений и владение хранилищем сохранены. На стандартный браузерный vault
BetterDiscord и синхронный Electron safeStorage эта замена процесса не распространяется.

## Открытый пункт полной версии Vencord

Зафиксированная основа Vencord (`32c90633ce6a95d7e56c95479efbb431bacf1eac`)
загружает в QuickCSS внешний Monaco 0.50.0. Пассивно полученный `editor.main.js`
содержит **DOMPurify 3.0.5**, SHA-256
`b5d16903e89e8baf0b747f38142ec3596a20a88bf48d08e7413911130270e5f7`.
Код скачан для чтения и не исполнялся. Версия попадает в диапазон
[официального advisory DOMPurify GHSA-gx9m-whjm-85jf](https://github.com/cure53/DOMPurify/security/advisories/GHSA-gx9m-whjm-85jf).

Наличие компонента подтверждено; эксплуатация через конкретные входные данные
QuickCSS не воспроизводилась. У окна выключен Node integration, включён context
isolation, выключен sandbox. Это не основание считать старый sanitizer безопасным.
**Массовый выпуск полной версии Vencord удерживается** до исправления зависимости
и проверки совместимости. Простая замена на минимальную версию из одного advisory
не закрывает более поздние advisories.

В BetterDiscord и уменьшенной standalone-сборке этого пути QuickCSS нет.
Аудит реестра зависимостей корня/BetterDiscord не сообщил известных уязвимостей.
Для upstream получены 66 advisory-записей / 55 GHSA; их нельзя представлять как
66 подтверждённых уязвимостей поставляемого плагина. Классификация разработки,
сборки, внешнего исполнения и фактического состава архивов сохранена в JSON.

## Приёмка и ограничения

На реальных клиентах остаются вход/перезапуск, вставка в текущий редактор Discord,
фокус нативных окон, обновление уже установленной версии и работа с настоящим API.
Краткий прогон готового файла не является новым многочасовым испытанием .23.
Настоящий отзыв доступа и неопределённый результат ротации refresh-токена могут
обоснованно требовать повторного входа — обещания «никогда не отключится» нет.

В этом цикле не выполняются установка в реальный Discord, отправка сообщений,
изменение production API или публикация GitHub Release. Все три пакета .23 —
локальные кандидаты для проверки, не объявление готовности массового выпуска.
