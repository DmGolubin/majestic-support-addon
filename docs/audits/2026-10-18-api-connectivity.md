# Доступность API панели — 18.10.2026

Владелец подтвердил адрес из переданного контракта:
`https://panel.majestic-rp.tech/api/plugin/v1`.

Выполнен один запрос `GET /me` без Authorization, cookies и Origin.
Получен ответ без перенаправления:

```json
{
  "status": 503,
  "contentType": "application/json; charset=utf-8",
  "error": "plugin_disabled",
  "code": "plugin_disabled"
}
```

HTTPS-сервер отвечает, но интерфейс плагина отключён. Это соответствует разделу
«Включение владельцем» полученного контракта: для допуска после проверки плагина
владелец устанавливает `PLUGIN_API_ENABLED=true` и перезапускает сервер штатным способом.
Секреты сервера и cookies сотрудника для этого плагину не нужны.

Проверка не подтверждает успешную авторизацию, доступ конкретного аккаунта, CORS
в Discord или работу остальных маршрутов. Device-коды и токены не запрашивались;
данные сотрудников не читались и не изменялись.

Разработка клиента и тесты по контракту могут продолжаться. Настоящий вход и
приёмка интеграции требуют допуска API владельцем; адрес повторно запрашивать не нужно.
