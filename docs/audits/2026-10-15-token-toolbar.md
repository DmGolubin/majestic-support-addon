# Панель переменных личного редактора — 15.10.2026

Добавлены кнопки Поле, Список, Дата, Время, Буфер, Выделение, Ссылка, Заголовок и Граница приветствия. Поле имеет имя и необязательное значение по умолчанию; список — имя и варианты по строкам. Дата/время поддерживают целочисленный сдвиг в минутах, часах, днях и неделях. Ссылка и заголовок означают канал Discord.

Вставка сохраняет позицию выделения textarea при переходе в конструктор, заменяет выделенный фрагмент и возвращает фокус в текст. Проверяются служебные имена, разделители синтаксиса и общий лимит 20 000 символов. Значения буфера и выделения не читаются редактором: он добавляет только маркеры.

Ограничение: кнопка «Каретка» отключена с пояснением. Ядро распознаёт маркер, но текущий адаптер вставки Discord не использует возвращаемую позицию. Не выдаём его за работающую функцию.

Проверки: 121 модульный тест; typecheck ядра. Браузерный стенд реальных компонентов с изолированным хранилищем проверил замену выделения, поле, список, дату со сдвигом, время, остальные маркеры, ошибки, сохранение и перезагрузку, ширину 400 px без горизонтального переполнения. Ошибок JS нет. Это не приёмка в живом Discord. API сайта не подключён.

Полный typecheck Vencord, ESLint изменённых файлов и итоговая сборка Vencord также прошли.
