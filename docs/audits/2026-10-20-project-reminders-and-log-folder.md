# A26 — папка журнала и настройки серверов

По живой проверке .33: Проводник сообщает о недоступном каталоге, настройки тикетов оставляют пустую правую часть, личные напоминания используют общий звук, подсказка Alt+стрелки непонятна.

## Объём

- Установить причину ошибки открытия реального каталога журналов и исправить общий native-путь для Lite, полного Vencord и BetterDiscord.
- Использовать всю доступную ширину; отдельные локальные включение, громкость и аудиофайл личных напоминаний Majestic / Россия Онлайн.
- Сохранить глобальный API discordEnabled и пороги Telegram. Локально выключенные проекты не выбираются для воспроизведения и не занимают очередь других проектов.
- Подпись порядка вкладок: «Перетащите вкладки в нужном порядке». Доступная клавиатурная перестановка остаётся.

## Проверки

В работе. Браузерная проверка с подставным shell не подтверждает открытие каталога в Windows. Для folder fix требуется отдельное подтверждение причины и native-пути. Фактическую слышимость оценивает пользователь.

Промежуточный общий прогон: 2320/2320, 126 файлов (`scripts/qa/runs/a26-suite-initial.log`); обе проверки типов прошли. UI-направление: 54/54 компонентных теста. Read-only ревью миграции/очереди/отмены не выявило замечаний. Родитель просмотрел exploratory скриншоты личных напоминаний 900×900 и 427×640: карточки используют ширину, на узком окне переходят в колонку. После просмотра убран искусственный предел 64ch у коротких подписей.

## Финальные проверки исходников

- 2331/2331 тест, 127 файлов; обе проверки типов прошли. Логи `scripts/qa/runs/a26-suite-final.log`, `a26-types-final.log`, `a26-vencord-types-final.log`.
- UI: 279/279, 52 снимка, 93 хеша стабильны. Агент просмотрел 9 снимков; родитель дополнительно проверил новые тикеты и личные напоминания при 900×720. Реальные pointer/keyboard действия и сохранение настроек проверены с подставными Discord/API/audio/native границами.
- Тесты включают отдельные громкость/файлы и миграцию прежнего общего звука, отсутствие расходования receipts выключенным проектом, выбор другого проекта, отмену при изменении локального переключателя и глобального API discordEnabled.

## Нативная папка

Подтверждено перенаправление логического LocalAppData в физический каталог MSIX `OpenAI.Codex…/LocalCache/Local`. Новый resolver использует `realpathSync.native`, когда он доступен, и сверяет тип каталога и dev/ino. Стандартный мост BetterDiscord без native-метода сохраняет canonical JS fallback; путь пакета не угадывается. Прежние проверки владельца/профиля/origin остаются.

Изолированный Electron 42.7.1 и Explorer COM подтвердили открытие физического каталога с main.log и совпадение идентичности папки. Исходная ошибка со скриншота в отдельном Electron 42.7.1/44.9.0 не воспроизведена; несовпадение путей — подтверждённый фактор, но не доказанная единственная причина исходного сбоя. Evidence: `scripts/qa/runs/a26-native-folder/explorer.json`, `checks.json`. Actual renderer после установки проверяется отдельно.
