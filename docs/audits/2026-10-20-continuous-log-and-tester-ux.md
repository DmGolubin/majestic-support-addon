# A22/A23 — журнал без срока и проверка замечаний тестеров

20.10.2026. Уточнение владельца: список замечаний относится к прошлой версии. Сначала проверяем текущую реализацию, не добавляем дубли. Отказ от четырёхдневного автоотключения — отдельное подтверждённое изменение требований.

## Что было и что изменено

| Пункт | Текущее состояние до работы | Изменение |
|---|---|---|
| Диагностика | Ограниченный JSON-снимок в TXT, четыре дня | Дописываемый TXT с временем, постоянная запись, ротация и миграция старого файла |
| API | Начало/результат запросов, SSE, вход/выход уже записывались | Дополнены причины отказа авторизации, обновления/очистки сессии, повторного подключения |
| Звук | Выключатель, громкость, загрузка/сброс и тест уже были | Разблокировка suspended AudioContext из действия пользователя, обратная связь теста, отмена pending/active playback, безопасные причины пропуска/ошибок |
| Общие первыми | Только ранжирование по совпадению | Настройка общих перед личными, релевантность внутри групп |
| Личные | Смешивались с общим списком | «Мои» и настройка включения личных во «Все»; избранное/недавние сохраняют обе категории |
| Порядок вкладок | Фиксированный | Перетаскивание и доступные с клавиатуры кнопки в настройках |
| Положение окна | Привязка к полю ввода | Перенос, закрепление, сброс, сохранение положения, границы viewport/title bar |
| Размер | Один верхний левый угол | Все стороны и углы, клавиатура, отмена незавершённого жеста |
| Без приветствия | Контекстное меню | Дополнительно Ctrl+левая кнопка через существующий insert API |
| Смена тикета | CHANNEL_SELECT явно закрывал окно | Окно остаётся на поддерживаемом сервере; старые операции/цели отменяются, список обновляет scope |

Сообщения по-прежнему только вставляются, отправки нет. В других серверах и ЛС окно закрывается. Изменение API сервера и автоматическая отправка диагностики не требуются.

## Журнал

Файл `SupportTemplates-diagnostics.txt` дописывается строками с местной датой и временем. Время/технические коды помогают сопоставлять отключение панели с запросами, обновлением сессии и действиями плагина. Только разрешённые метаданные: без токенов, текстов сообщений/шаблонов, значений полей, нажатий клавиш, имён аудиофайлов, заголовков и тел запросов.

Запись включена по умолчанию без срока. Выключение сохраняется. История не обнуляется при перезапуске. Текущий файл и девять архивов ограничены 10 МиБ каждый. JSON-кнопка явно названа «Скачать краткий отчёт»: это буфер последних 2000 событий, а не полная файловая история. Для старых проблем нужны TXT и архивы по пути из настроек.

Очередь ограничена; потеря при переполнении обозначается счётчиком. Аварийное завершение может потерять ещё не записанные события. Диагностика не гарантирует фиксацию аварии ОС и не измеряет весь процесс Discord.

## Дополнительное ревью

Исправлены четыре воспроизводимых пограничных случая:

- Новый выбор шаблона после замены editor DOM использует новое поле. Уже начатая операция сохраняет старую цель и отменяется.
- Повторное открытие ждёт очереди сохранения положения.
- Клавиатурные движения не сохраняются внутри незавершённого pointer-жеста; Escape отменяет жест.
- Обновление каталога убирает устаревшие hover-текст и таймер.

UI: 169 проверок, 0 ошибок; реальный React/контроллеры из исходников, browser pointer gestures и localStorage, адаптеры Discord/API/аудио заменены fixtures. Файловый benchmark: 100 последовательных маленьких append на заполненном 9,87 МиБ файле и 424 КиБ состоянии восстановления. Изолированный прогон: медиана 56,7 мс, p95 65,7 мс, максимум 78,5 мс. Во время полного параллельного набора: медиана 76,3 мс, p95 125,7 мс, максимум 159,2 мс. Активный лог при обычном дописывании не читается целиком; состояние восстановления записывается отдельно. Важное ограничение: host-адаптер использует синхронные файловые операции; результат не означает нулевую нагрузку или отсутствие задержек на медленном диске.

Уточнено логирование: `auth.rejected` только при 401/session_revoked; сетевой timeout уже отражается в `stream.failure`, не означает выход. Регрессия stream timeout сохраняет connectionId и не пишет отказ авторизации. После уточнения прошли 132 целевых теста и проверка типов (`a23-auth-event-final.log`).
