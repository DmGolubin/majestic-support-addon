# A27 — личные шаблоны и очистка элементов управления

Владелец проверил .34: тяжёлый hover панели перемещения, лишняя кнопка меню строки, ненужные пояснения проверки звука и общего переключателя, неоформленный общий блок проигрывания. Запрошены временный ручной показ уведомления и личные шаблоны в обоих проектах.

## Объём

- Удалить видимую кнопку действий строки, сохранить правый клик и доступную клавиатурную альтернативу.
- Убрать широкую заливку drag-панели и сделать спокойное наведение иконок.
- Удалить подписи «Проверка: … без включения канала» и «Общий переключатель для всех серверов»; сам API-переключатель оставить.
- Компактный статус проигрывания с выровненной остановкой звука.
- Временная локальная кнопка тестового уведомления через тот же host toast; без API, тикетов и receipts.
- Доступные личные шаблоны видны в обоих разрешённых проектах. Исходные записи и права панели сохраняются, FAQ команды остаются по проектам.

## Проверки

- Независимое ревью shared personal: замечаний нет. Доступ берётся из проверенного snapshot; отзыв прав, смена аккаунта и выход отменяют устаревшие вставки. Исходные project/folder/version/shared сохраняются при редактировании, массовой перезаписи API нет.
- Финальные root/Vencord typecheck проходят.
- Browser fixture: 171/171 проверок при 1200×900, 900×720, 427×640 и 320×568; 93 исходных хеша неизменны. 36 снимков, 7 проверены визуально. Файлы: `scripts/qa/runs/a27-ui/final-02/regression.json` и `visual-inspection.json`. Реальные компоненты/контроллеры, host toast, AudioContext, API и вставка заменены фикстурами. Четыре exploratory падения были ошибкой самой фикстуры (`null → all`), исправлены в harness.
- Первый полный прогон при параллельной нагрузке: 2359/2360, один сбой bounded Windows DPAPI subprocess. Изолированный повтор неизменённого файла: 10/10. Таймауты и проверки не ослаблялись. Финальный полный прогон без параллельных тяжёлых проверок: **2360/2360, 128 файлов**, 99.83 с (`a27-suite-final.log`).
- `graphify update .` обновил игнорируемый граф: 4498 узлов, 9000 связей.
