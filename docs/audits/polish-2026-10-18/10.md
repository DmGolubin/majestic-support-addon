## 1. P2 — Replaced editor permanently blocks retries of a collected reply

- **Location:** `src/vencord/ui/ComposeBar.tsx:89` (early return); recovery exists only at line 103.
- **Trigger:** Collect a reply, then let Discord replace its Slate editor without changing channels (or close the targeted side editor while another editor remains available). Click “Вставить всё” after the captured editor has disconnected; retry the button.
- **Consequence:** `stillCurrent(snap)` rejects the disconnected editor at line 89. This bypasses `resetComposeTarget()` at line 103. Every later click captures the same disconnected target and cancels again; the collected reply remains but cannot be inserted by retrying. The bar can still be displayed because `chatAreaEl` falls back to the active editor for disconnected targets. Collecting another piece or rebuilding the reply is required to refresh its target.
- **Minimal fix:** On the initial `stillCurrent(snap)` rejection, also reset the compose target if its editor is disconnected, then cancel this attempt. Preserve the existing policy that a subsequent explicit click chooses the current editor; do not insert into another editor automatically during the failed attempt.
- **Evidence:** Executed an isolated stdin Node reproducer using TypeScript transpilation and VM evaluation of the actual ComposeBar and actual flow.ts `snapNow`/`stillCurrent` implementations. UI hooks, store, geometry and platform were stubbed; the library was fresh, channel/scope/generation/version stable, and the captured editor had `isConnected: false`. Two clicks yielded `{"attempts":2,"resets":0,"fills":0,"inserts":0,"compose":["a"]}`. Assertions confirmed no reset, no insertion and retained composition. No reproducer file was written. This confirms the control-flow defect; Discord's live editor replacement was not exercised.
- **Suggested regression:** Disconnect the captured editor before the first click; verify cancellation resets the target, retains collected IDs, and permits a second click targeting a connected editor.
