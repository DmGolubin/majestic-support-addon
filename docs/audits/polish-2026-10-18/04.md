Existing tests cover a stalled fetch and stalled response body, cancellation and cleanup. `PanelClient.mutate` captures retry inputs; no transport retry of an uncertain POST/PATCH or refresh was found. This does not establish whether a timed-out server write committed.
- **CORS assumptions:** `panelTransport.ts:98–108` uses Bearer headers and omits cookies; it does not forge an Origin. The delivered contract explicitly allows Discord/PTB/Canary origins and desktop requests without Origin. Actual preflight handling and exposure of Retry-After depend on the server and cannot be proven with mocked fetch tests.
