## 1. P2 — Greedy subsequence start loses valid fuzzy matches

- **Location:** `src/core/search.ts:54–61` (`subseqSpan`), consumed at `src/core/search.ts:67–68`.
- **Trigger:** Import `tests/fixtures/config-0.5.1.json` using `importBackup`, filter project `mj`, call `search(mj, "рздел")` (one missing letter in «раздел»).
- **Actual:** Zero hits. «Направление в технический раздел форума» is omitted. `subseqSpan("рздел", hard(title))` returns 29: it starts with the earlier «р» in «Направление». The valid subsequence within «раздел» spans only 6 characters, below the allowed 15.
- **Consequence:** Common single-letter omissions fail depending on earlier words in the title. Also reproduced `разел` and `раздл` returning zero results for the same title.
- **Minimal fix:** Compute the shortest complete subsequence span, or retry subsequent candidate start positions before rejecting the span. Preserve the existing fuzzy threshold and strict-first behavior.
- **Evidence:** Isolated stdin Node reproducer transpiled the actual TS modules in memory with installed TypeScript, imported the checked-in fixture, and compared the original span against all possible start offsets. Output: `{title:"Направление в технический раздел форума",q:"рздел",span:29,best:6,hits:[]}`. No reproducer files or shared tests were written. Add a regression with this real title and query.

## 2. P2 — Alias title keys no longer match existing library titles

- **Location:** `src/core/aliases.ts:23` (Steam key), `src/core/aliases.ts:37` (Media key); attachment uses `src/core/search.ts:25`.
- **Trigger:** Search the same checked-in Majestic fixture for `стример`. The pool contains «Вопросы по Media», but the alias key is «вопросы по медиа». Similarly, the Steam key is «запускается версия стим», while the fixture title is «Запускается версия Steam».
- **Actual:** `search(mj, "стример").hits` is empty. Direct normalized title-key checks confirm neither alias entry attaches to any template in the full 133-template fixture. The intended Media alias explicitly includes `стример`.
- **Consequence:** Documented synonyms silently stop finding the matching template after title wording/script changes.
- **Minimal fix:** Add title-key variants for the existing Media and Steam titles while retaining old variants if still supported. Add a fixture-backed regression asserting `стример` finds «Вопросы по Media» at alias level 3; verify Steam aliases against its current title too.
- **Evidence:** Isolated execution against actual modules printed the present title, the unmatched alias key, and `стример []`. This is verified against the committed fixture; no live catalog was accessed, so occurrence in the current account catalog is unverified.

## Accepted fixes — completed 2026-10-18

- **Finding 1 fixed:** `subseqSpan` now retains the latest start for each matched needle prefix and returns the shortest completed span. Reverse prefix iteration prevents reusing a haystack character for repeated needle letters. Complexity is O(title length × query length), with O(query length) temporary storage and an early exit for a contiguous match. Empty or impossible needles return -1. The existing minimum length, single-token restriction, 3× span threshold, and strict-first fallback are unchanged.
- **Finding 2 fixed:** Added `запускается версия steam` and `вопросы по media` alias keys alongside the original Cyrillic variants. Both legacy variants remain covered.
- **Regressions:** Real fixture titles now match `рздел`, `разел`, `раздл`, `стример`, `стим`, and `steamapi` at the expected levels. Tests also cover legacy aliases, strict body hits suppressing fuzzy fallback, the exact 3× threshold and just-over-threshold rejection, short and multiple tokens, repeated needle letters, absent matches, and a later shorter complete match.
- **Targeted verification:** `node node_modules/vitest/vitest.mjs run tests/search.test.ts tests/rank.test.ts` — **33/33 passed**, 2 files (18 added search cases).
- **Independent correctness check:** An isolated stdin script compared the actual `subseqSpan` implementation with exhaustive substring/subsequence enumeration for every binary-alphabet needle of length 0–4 and haystack of length 0–7: **7,905 cases passed**. No additional files were created.
