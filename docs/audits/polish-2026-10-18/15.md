## Verified finding

1. **P2 — Supported panel colors render as gray palette swatches.**
   - **Location:** `src/vencord/ui/ColorPicker.tsx:37` passes the original wire name into `data-color`; `src/vencord/styles/color-picker.css:14` supplies the gray fallback, while lines 15–22 only define red/orange/amber/green/teal/blue/violet/pink. The fallback label map at `ColorPicker.tsx:17–20` also omits yellow/purple/cyan.
   - **Trigger:** Open a personal-template editor with a catalog whose `limits.colors` includes `yellow`, `purple`, or `cyan`. These are explicitly supported by `src/core/panelCatalog.ts:143–144`; catalog colors remain wire names at line 285 and are passed directly to the picker at `src/vencord/ui/PanelPersonalLibrary.tsx:210`. The existing snapshot fixture in `tests/panelCatalog.test.ts:18` already includes yellow and purple.
   - **Consequence:** Each affected option shows the same gray swatch, despite the template's catalog color being yellow, violet, or teal. Without server labels it also falls back to the English wire name. Selecting a color therefore gives a misleading visual indication.
   - **Minimal fix:** Add swatch selectors for yellow (`#eab308`), purple (`#8b5cf6`), and cyan (`#14b8a6`), plus their Russian fallback labels. Keep wire values and callbacks unchanged.
   - **Evidence:** An isolated in-memory Node/TypeScript VM reproducer executed the actual `ColorPicker` with `colors: ['yellow', 'purple', 'cyan']`, asserted that all three swatches carry those wire names, asserted the catalog has corresponding real color mappings, and asserted no matching selectors exist in the imported picker stylesheet. All assertions passed with `target: ES2022`. An initial harness run used TypeScript's default ES5 target and failed to expand the Set; correcting the harness target resolved that harness-only failure. No files were created for the reproducer.
   - **Regression coverage to add when fixing:** Exercise the documented catalog palette, including aliases, and verify corresponding visual mappings and fallback labels. Existing editor tests use only amber and do not detect this mismatch.
