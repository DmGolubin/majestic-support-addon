# A21 — общий интерфейс и две публичные поставки

Дата: 20.10.2026. Исходный коммит пакетов: `0766b3090e33ce8b3d1e6a9a25a08289f60b1a71`.
Техническая версия: `1.0.1-canary.27`. Статус: **готово к живой приёмке**, не опубликовано.

## Изменения

- Две публичные поставки: **SupportTemplates Lite** и **SupportTemplates для BetterDiscord**.
  Полный Vencord остаётся отдельной личной сборкой; публичный publisher отклоняет лишние пакеты.
- Общий UI/ядро и единственный источник версии `distribution/config.json`.
  Видимая подпись `SupportTemplates [Lite] · 1.0.1 · тестовая`.
  Полная техническая версия остаётся в диагностике/подсказке и протоколе обновлений.
- Один основной счётчик шаблонов. При фильтрации `N из M`; повторные числа у категории удалены.
- Настройки размывают фон и закрываются по нажатию на него. Несохранённые изменения
  требуют выбора, активное сохранение не прерывается. Верхняя полоса окна исключена
  из покрытия; высота настроек учитывает её и на узких экранах.
- Компактная карточка аккаунта: имя, состояние, выход, небольшие серверные иконки с
  подписями. Повтор подключения доступен при ошибке; служебные объяснения удалены.
- Lite предлагает выбрать установленный Stable/Canary. Нет неявного Canary.
  Проверки чужой установки, владения файлами, остановленного процесса и путей сохранены.
- Loader Lite использует `original-fs` для физических ASAR-проверок. Синхронный native
  startup сохранён; обновления начинаются после ready.
