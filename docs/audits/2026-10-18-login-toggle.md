# A16: кнопка окна входа и сообщение о недоступности панели

## Изменения

- Повторный клик по кнопке шаблонов закрывает экран входа. Раньше обработчик внешнего `mousedown` закрывал его до `click`, после чего общий переключатель вновь открывал окно. Теперь кнопка и её вложенная иконка исключены из обработки внешнего нажатия, как уже было в основном окне шаблонов.
- Клик вне окна по-прежнему закрывает его; клик внутри не закрывает. Закрытие окна не отменяет авторизацию само по себе: это прежнее поведение.
- Для `plugin_disabled` показано: «Подключение к панели пока недоступно. Попробуйте позже.» Серверный код и обработка ошибки не изменены.

## Проверки

- Регрессионный тест исполняет настоящий обработчик LoginWindow и переключатель из index.tsx в порядке mousedown → click. На прежнем коде он падал из-за повторного открытия, после правки проходит. Проверены повторное открытие и клики внутри/снаружи.
- 53 теста demoLifecycle/panelIntegration проходят; проверка типов текущего плагина в Vencord проходит через виртуальное наложение исходников, без изменения установленного Vencord.
- Собран отдельный пакет 0.1.0-canary.2 из коммита af71592, 193 входных файла, проверки состава сборки проходят.
- ZIP и распакованный пакет: `artifacts/standalone/0.1.0-canary.2-af71592/` (локальные артефакты, не опубликованы).
- Установка пока не выполнена: Canary запущен, установщик отказал до изменения файлов. Запрошено закрытие только Canary. Рабочий Stable не менялся.

Это проверка исходников и сборки. Живой повторный клик в новой версии требует её установки; настоящий API здесь не проверялся.
