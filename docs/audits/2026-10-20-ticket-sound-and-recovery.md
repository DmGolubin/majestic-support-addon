# A24 — причины звуков и работа при временной недоступности панели

Запрос владельца 20.10.2026: различать источники звука, видеть конкретный тикет/канал и причины решений, настраивать каналы отдельно, продолжать работу с загруженной библиотекой при кратком сбое API. Проверить замечания старой .29 по биндам и закрытию окна.

## Подтверждённые исходные данные

Лог BetterDiscord .29, переданный владельцем: 2000 сохранённых событий за 10:58:27–11:42:45 UTC, 1410 событий вытеснены. 267 успешных запросов, 33 `network_error` (5159–5811 мс), 41 сбой SSE (5139–5898 мс). Три успешных refresh, в сохранённом фрагменте нет отзыва сессии. Некоторые HTTP 200 обрываются при чтении body. По коду .29 ошибка повторной загрузки временно сбрасывает ready, и окно показывает подключение. Журнал не устанавливает причину обрывов сети, серверный виновник не доказан. Присланные ZIP/TXT содержат одинаковый журнал.

## Границы изменений

- Локальная диагностика технических ID тикета, канала, сервера разрешена владельцем для расследования уведомлений. Без ID сотрудника, текстов сообщений, токенов, содержимого запросов и аудиофайлов.
- «Новый тикет» и «Игрок ждёт ответа в назначенном тикете» — разные функции. Отключение одной не должно выглядеть как отключение обеих.
- Обнаружение события, решение, запуск аудио и результат — отдельные факты. Запуск AudioContext не доказывает физическую слышимость.
- Настройки новых тикетов раздельно для каналов Majestic и России Онлайн; существующие серверные настройки личных напоминаний сохраняются.
- Уже проверенная библиотека остаётся доступной в памяти той же сессии при временном сбое на ограниченный срок. Отзыв доступа, смена аккаунта/прав и выход закрывают доступ. Записи на панель и напоминания не используют устаревшее подтверждение.
- Состояния до HTTP headers и ошибка чтения body различаются в диагностике; сохранение status 200 не выдаётся за успешно полученный ответ. Только статические категории ошибок, без текста исключений.

## Приёмка

- Общий прогон: **2225/2225**, 123 файла (`scripts/qa/runs/a24-suite-final2.log`). Четыре прежних ожидания обновлены под ready+stale и новую подпись личного звука; ограничения частоты запросов не ослаблены.
- Обе проверки типов прошли: общий TypeScript и текущий исходник на закреплённой версии Vencord.
- Браузерный UI: **141/141**, 33 снимка при 320×568, 427×640 и 1200×900. Проверены реальные компоненты/контроллер звука с подставными API/хостом/AudioContext. Все 66 хешей исходников стабильны; browser errors и неожиданных запросов нет. Артефакты: `scripts/qa/runs/a24-ui/final-02/`. Родитель дополнительно просмотрел узкое окно с сохранённой библиотекой и широкие настройки каналов.
- Срок сохранения проверенной библиотеки — максимум 15 минут от последнего успешного подтверждения, только в памяти текущей сессии. Тесты проверяют истечение, выход, смену аккаунта/прав, pending resync и запрет записи без свежей проверки. Обрыв SSE сам по себе не выключает независимые свежие проверки назначенных тикетов.
- Произвольные бинды уже существовали; добавлена явная кнопка действий у строки, обработка фокуса и подтверждение замены занятого бинда. Закрытие при смене тикета исправлено ранее в .31.
- Личные напоминания проверяются по назначению текущему сотруднику и свежему снимку. Неправомерный сигнал из сообщения тестера не воспроизведён. Добавлены стадии отбора, причины пропуска, выбранный тикет, проверка перед воспроизведением и результат.
- Технические snowflake ID канала/сервера сохраняются; непрозрачные ID тикетов и циклов хешируются. Текст исключений, API body, токены и содержимое аудио в журнал не попадают.
- `graphify update .` выполнен: 4366 узлов, 8676 связей.
