# Приёмка демонстрационного сценария в Discord — 16.10.2026

## Результат и границы

Приёмка демовхода, ошибок подключения, поддерживаемых переменных и личного редактора завершена в установленном Discord с новой сборкой Vencord. Проверялись реальные окна плагина; подтверждение и сбои задавались через локальную демонстрационную панель. Сообщения в чат не отправлялись: результат вставки проверялся в черновике и удалялся.

Это готовность демонстрации, а не приёмка настоящего API сайта или разрешение на массовую раздачу. Реальные токены, серверные права, двусторонняя синхронизация личных записей, конфликты и несколько устройств остаются C03–C09. Обычная библиотека отделена от демоданных.

## Проверено в живом Discord

| Сценарий | Результат |
| --- | --- |
| Подтверждение входа | Загрузка библиотеки и компактное меню |
| Отказ на панели | Сообщение об отказе; новый вход доступен |
| Отмена в плагине | Ожидание прекращается, прежний код убирается |
| Просроченный код | Понятное сообщение; повторная попытка работает |
| HTTP 503 после подключения | Отдельная сцена восстановления, автоматический возврат меню |
| Отзыв устройства | Библиотека закрывается; предложен новый вход; повторный вход успешен |
| Обновление FAQ | Версия 1 меняется на 2; меню и вставка используют новый текст |
| Личный шаблон | Создание, редактирование, синий цвет, общий проект |

| Удаление копии | Удалена только копия; оригинал остаётся |

HTTP 503 моделировался локальным сервером на 20 секунд. Физическое отключение сети не выполнялось. Существующие проверки папок, адаптивности и элементов управления описаны в отчётах от 15 октября; они не выдаются за повторную полную матрицу устройств.

## Переменные

В живой вставке проверены `{{имя=Игрок}}`, обязательное `{{номер}}`, выбор `{{проект|Majestic|РО}}`, `{{date}}`, смещения даты на день вперёд и назад, `{{time}}`, смещение времени на час, `{{clipboard}}`, `{{selection}}`, `{{url}}`, `{{title}}`. Выделение сохранялось при открытии меню и диалога. URL и заголовок соответствовали текущему каналу. Маркер `[[greeting:end]]` не попадал в итоговый текст.

Буфер после исправления вставил контрольную строку «ТЕСТ-БУФЕР». Отдельный стенд настоящего адаптера проверил пять вариантов: native, пустой native, browser, fallback после ошибки native и отказ обоих способов. Последний возвращает null; вставка отменяется с уведомлением. Поддержка позиционирования курсора `{|}` не заявляется. Кнопки вставки переменных в редакторе дополнительно проверены браузерным стендом.

## Найденные и исправленные ошибки

1. После потери связи экран снова просил подтвердить уже подтверждённый вход. Добавлена отдельная сцена восстановления без старого кода; проверена повторным 503 в Discord.
2. Web Clipboard API в Discord возвращал отказ, а плагин молча подставлял пустую строку. Добавлен native clipboard Discord с браузерным fallback и явной отменой при недоступности; повторная живая вставка успешна.
3. «Создать копию» сохраняло старый ID из объекта редактора и перезаписывало оригинал. Ядро теперь собирает разрешённые поля явно. Регрессионный тест сначала воспроизвёл ошибку, затем прошёл; создание и удаление копии повторно проверены в Discord.

## Небольшие дополнения

- Версия плагина и идентификатор сборки добавлены в отчёт отладки; проверены исходники и сборка.
- Для бинда другого проекта на Tech добавлена однократная подсказка без перехвата клавиши. Проверено по коду и сборкой; отдельная живая проверка этого бинда не выполнялась.
- Демо-панель получила управляемые сценарии просроченного кода и HTTP 503.
- Roadmap разделён на готовность показа, выпуск команде и подключение сайта. Шаги свёрнуты, ближайшие задачи видны отдельно; поиск по ID и переход из карточки работают. Браузерный стенд проверил фильтры и ширину 390 px.

## Автоматическая проверка

126 тестов, typecheck ядра и Vencord, ESLint плагина и сборка Vencord проходят. Сборка синхронизирована и загружена в Discord через Ctrl+R. Последняя повторная живая проверка копирования выполнена после сборки с исправлением ID.

## Остаток

В редакторе после удаления карточки может оставаться прежнее сообщение «Шаблон сохранён». Это косметическая неточность уведомления; данные при удалении проверены и корректны. Отмечено отдельно в roadmap. Выпуск, документация установки и production API не закрываются этим отчётом.
