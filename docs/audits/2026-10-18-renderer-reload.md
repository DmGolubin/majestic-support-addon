# Обновление Canary через Ctrl+R — 18 октября 2026

## Изменения

Добавлены `UpdateRenderer` и `update.bat`. Режим не останавливает Discord и не меняет архив загрузчика, main/preload, настройки или токены. Сравнивается исполняемый код main/preload (исключена только генерируемая первая строка версии), код загрузчика, upstream и допустимый набор файлов. Изменение native требует полной установки.

Для совместимого выпуска CSS из проверенного пакета встраивается в единственный вызов получения стилей renderer.js. Итоговый JavaScript публикуется атомарно; Ctrl+R не может смешать версии JS/CSS. Оригинальный пакет .7 сохраняется отдельно и без изменений. В версии базового runtime заменяется только renderer.js; внешняя запись обновления хранит проверяемые хеши оригинала, предыдущей и новой версии, а также атомарно опубликованные копии для восстановления. Status различает базовый runtime и интерфейс, а после прерывания сообщает pending; повтор UpdateRenderer завершает операцию.

Успешная полная установка снимает overlay после ресурсной транзакции. Ошибки проверки и откат транзакции сохраняют текущий интерфейс. Повторная установка после удаления также снимает сохранённый overlay целевой версии. Старые установщики до этого изменения не знают о записи обновления: для Status/Repair/Install нужно использовать новый пакет с RendererUpdate.ps1.

## Проверки

Пробный UpdateRenderer -WhatIf на настоящем .6 → .7 разрешил совместимое обновление без записи. Независимое ревью подтвердило чтение JS при каждом preload-запросе и отсутствие production CSS watcher. Встраивание CSS сохраняет существующий style.textContent и порядок CSS. Source map исходного renderer после встраивания CSS не соответствует новым позициям: это ограничение диагностики, не исполнения.

22 теста standalone build/loader проходят; node --check проходит для подготовленного и фактически установленного файла. Тестовый .6 → .7 при работающем хосте прошёл, включая встроенные стили, неизменность native/конфигурации и повторный запуск. Базовый прогон установщика завершён: 24 выполненные группы прошли; группа real-payload без параметра PayloadPackageRoot пропущена (runner печатает 25 групп с учётом неё). Все 15 новых групп UpdateRenderer прошли, exit code 0, PowerShell 5.1.26100.9711: обновление при работающем хосте, встроенные стили, идемпотентность, совместимость загрузчика, отказы native, подмена, прерывания, последовательные версии, полная установка/rollback/repair, отказ транзакции на каждом шаге и восстановление cleanup после commit. Итого 39 выполненных установочных групп прошли; одна дополнительная real-payload группа пропущена.

UpdateRenderer успешно применён к реальному Canary. Status показывает базовый runtime 0.1.0-canary.6 и Renderer 0.1.0-canary.7. Проверка хешей подтвердила: среди прежних файлов ресурсов/runtime изменился только renderer.js. В момент активации Canary уже был закрыт; после установки запущен обычным EXE. Поэтому успешное обновление работающего хоста подтверждено фикстурами, а реальный Ctrl+R и внешний вид ожидают подтверждения владельца.

## Живая проверка

Инструмент Windows computer-use дважды не запустил kernel (после сброса та же ошибка отсутствующего пути). Поэтому автоматическое Ctrl+R и осмотр окна недоступны в этом запуске; после установки сочетание нажимает владелец. Это не блокирует установку файлов через проверенный UpdateRenderer.
