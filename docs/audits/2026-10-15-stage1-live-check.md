## Ограничения инструмента и промежуточный список

Инструмент управления Windows передаёт некоторым клавишам пустой `KeyboardEvent.code`. Поэтому Ctrl+Alt+T не сработал через этот инструмент; обработчик отдельно сработал от синтетического события с code=KeyT в настоящем Discord. Это **не** подтверждение физической горячей клавиши. Tab, Escape и Shift+Enter сработали через обычный ввод инструмента.

На этом промежуточном шаге оставались импорт, длинная форма, удержание клавиш и мыши, Shift+wheel, ЛС, сохранение Tech и размеры/масштаб. Результаты продолжения приведены ниже. Ограничение физического ввода Ctrl+Alt+T сохраняется: его обработчик проверен синтетическим событием с корректным code, а не физической клавиатурой.

- Ctrl+- уменьшает интерфейс, Ctrl+= увеличивает; окно, поиск, список и нижние подсказки остаются видимыми. После каждой проверки выполнен Ctrl+0, исходный масштаб 100% восстановлен. Точные значения промежуточных ступеней отдельно не снимались.

В процессе наблюдалось запаздывание интерфейса после reload; на финальном запуске после ожидания 10 секунд кнопка видима. Предположение об исчезновении кнопки отдельно проверено через DOM: зарегистрирована, её элемент имеет ненулевой rect и видимые стили. Новый дефект исчезновения этим не подтверждён.

### События DOM в живом клиенте — не физическое удержание

Эти сценарии выполнялись на настоящих компонентах и обработчиках установленного плагина через консоль Discord. Платформа не заменялась заглушкой. Ограничение: синтетические события не воспроизводят все доверенные браузером действия физического устройства.

| Сценарий | Наблюдение |
| --- | --- |
| Enter с `isComposing=true` в форме | Диалог остаётся открыт, вставки нет |
| Импорт при открытой форме | Реальный обработчик Settings импортирует набор; старая форма закрывается, прежний текст не вставляется |
| Остановка плагина при открытой форме | Диалог закрывается, отложенной вставки нет; затем плагин запущен снова |
| Shift и Shift+wheel над длинным превью | Превью открывается; колесо с deltaX сдвигает scrollTop; событие обработано |
| Ctrl+Shift+wheel | Плагин не отменяет событие и не прокручивает превью |
| Отпускание Shift | Превью скрывается |
| Закрывающий меню клик с задержкой mouseup 1100 мс | Меню закрывается, шаблон не вставляется |
| Enter в форме, затем 20 повторов за 600 мс | Вставка один раз; все 20 repeat keydown отменены обработчиком; keyup освобождает latch |

При тесте импорта во время формы использован настоящий компонент Settings; только системный выбор файла заменён программной передачей того же тестового File. Временная подмена `HTMLInputElement.prototype.click` восстановлена в finally, временный React root удалён. Временный обработчик измерения resize также снят. Результаты сохранены локально в `SupportTemplates_acceptance_results_20261015`; временные globals исчезли после reload.
