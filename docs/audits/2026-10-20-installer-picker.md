# D16 · Выбор клиента в полном Vencord

Для Windows подготовлена отдельная редакция установщика `setup2` поверх
проверенного runtime `1.0.1-canary.24`. Изменение находится в коммите
`d43e7232786783fc959df4f30925848adb82cd23`.

При открытии любого BAT полного Vencord без `-Channel` скрипт ищет обычный Discord
и Discord Canary в стандартном LOCALAPPDATA. Показывает найденные клиенты и пути,
просит номер. Даже при одном найденном клиенте требуется выбрать его.
Enter/0 отменяет действие без записи файлов; неверный номер повторяет вопрос.
При отсутствии поддерживаемых установок выводится ошибка. PTB и portable пути
в этой редакции не добавлены.

`-Channel Stable` и `-Channel Canary` продолжают работать без запроса.
Выбор происходит перед созданием каталога канала, блокировки и транзакции.
Дальнейшие проверки закрытого клиента, чужих модификаций, ссылок/junction,
целостности и отката сохранены. Скрипт не закрывает Discord самостоятельно.
Выбор работает также для Update/Repair/Rollback/Status/Uninstall.

## Проверка

Проверки выполняются Windows PowerShell 5.1 исключительно в отмеченных TEMP
каталогах. Шесть новых сценариев: один найденный клиент с отменой; только Stable;
оба клиента и неправильные номера; пустой ввод и явный `-Channel`; выбор Canary
при наличии обоих; отсутствие подходящей установки. Проверяется неизменность
невыбранного клиента и файлов при отмене. Также выполняется существующая
регрессия установщика, включая настоящий payload .24.

Итог: **31 группа прошла, пропусков нет**. Первые 24 группы прошли в общем
прогоне. Старая проверка BAT ожидала неявный выбор Canary, поэтому при новой
отмене по EOF ошибочно ожидала код ошибки. В ней явно задан `-Channel Canary`;
эта и шесть оставшихся групп прошли отдельным прогоном. Это не один полностью
зелёный общий запуск; байты продукта между прогонами не менялись.

Финальный ZIP повторно распакован; все 35 payload-хешей, manifest и новый
установщик совпали с проверенными файлами. Итог прогонов и SHA-256:
[installer-picker-results.json](2026-10-20-installer-picker-results.json).

Живая проверка на машине получателя остаётся необходимой. Обновление не
добавляет поддержку macOS и не изменяет установщик standalone.
