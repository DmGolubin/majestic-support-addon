# Показ SupportTemplates — 16 октября 2026

## Перед собранием

1. В репозитории запустить `powershell -File scripts/start-meeting-demo.ps1`: локальные серверы демопанели и roadmap. Уже работающие процессы не перезапускаются.
2. Открыть http://127.0.0.1:47834/meeting/ — сценарий и резервные скриншоты.
3. В Discord открыть свой тестовый тикет либо Tech. Перед звонком обновить клиент Ctrl+R; во время голосового собрания этого не делать.
4. Войти через панель из меню шаблонов, сверить код, подтвердить на локальной странице. Сохранить вкладку подтверждения: там можно обновить FAQ.
5. Не включать подробную отладку для обычного показа. В демо личные записи исчезают после перезагрузки — подготовить их после последнего Ctrl+R.

## Сценарий на 5–7 минут

| Время | Действие | Что объяснить |
| --- | --- | --- |
| 0:00 | Открыть меню → вход → подтверждение → загрузка | Один аккаунт панели; текущий показ использует локальный демосервер |
| 1:00 | Компактный список, Shift, вставка в пустой черновик | Быстрый просмотр и вставка; отправку выполняет человек |
| 2:00 | Мои шаблоны → папка «Собрание» → добавить пример ниже | Личный редактор, цвет, команда, общий проект |
| 3:00 | Вызвать `;уточнение` и заполнить поле | Переменные заполняются перед вставкой; ничего автоматически не отправляется |
| 4:00 | На вкладке демопанели изменить FAQ → сохранить | Получение обновлённого основного FAQ; в демо опрос каждые 2 секунды |
| 5:00 | Настройки и roadmap | Что готово, что ждёт приёмки/API, что отложено |

На Tech выбранный проект должен совпадать с шаблоном либо шаблон должен быть общим. После обновления FAQ окно может закрыться: открыть снова и выбрать обновлённый ответ. Тексты вставлять только в собственный тестовый черновик, затем очистить обычным Ctrl+A / Backspace.

## Пример личного шаблона

- Название: «Уточнение обращения»
- Папка: «Собрание»
- Проект: общий
- Цвет: синий
- Команда: `уточнение`

```text
Здравствуйте, {{имя}}!
[[greeting:end]]
Уточните, пожалуйста, когда появилась проблема и какие действия вы выполняли перед ней.
Приложите скриншот ошибки — это поможет нам разобраться.
```

Для показа обновления основного FAQ добавить на локальной странице строку: «Также укажите, повторяется ли проблема после повторного входа». Это пример текста, не новый обязательный регламент поддержки.

## Что можно утверждать

Рабочая Vencord-версия: поиск, избранное, недавние, быстрые команды, предпросмотр, поля, составной ответ, защита проекта, личные шаблоны/цвета/папки. Новые экраны проверены браузерным стендом. Базовая приёмка Discord была выполнена отдельно; текущий проход её не заменяет.

Подключение настоящего сайта пока не готово. Демовход и обновление FAQ идут через локальный сервер. Личные записи сейчас локальные, в демо — временные; двусторонней синхронизации нет. Токен приложения не должен разрешать менять основные FAQ, даже старшему. API-контракт подготовлен для разработчика панели.

BD-версия, звуки тикетов, таймер ответа, автоподбор по обращению и статистика — будущие этапы. Ни автоотправки, ни автозабора тикетов нет.
