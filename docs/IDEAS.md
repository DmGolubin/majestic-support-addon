# Идеи, решения и открытые вопросы

Сводка обсуждения 05–06.10.2026 (полный чат — `docs/history/chat.md`, спек — `docs/superpowers/specs/`).

## Откуда всё началось

- BD-плагин SupportTemplates 0.5.1 от persephonemajestic (`reference/bd-0.5.1/`), тот же код, что в
  `github.com/persephonemajestic/BetterDiscord-SupportMajestic`. `PLUGIN_ID` в обоих — `SupportTemplates`,
  поэтому два файла в папке plugins = два активных плагина и двойная вставка.
- Фидбэк саппорта: (1) после Alt+N текст иногда не стирается — лечится сменой вкладки;
  (2) кнопка «Назначить» даёт миссклики; (3) вкладка проекта должна оставаться по каналу.

## Разбор багов 0.5.1

1. «Призрачный» текст — рассинхрон Slate: окно проверки вставки 150 мс → запасные `execCommand`/paste
   меняют DOM в обход модели; Alt+N без проверки `e.repeat`; проверка смотрит в первый редактор на
   странице, а Discord вставляет в последний активный; `INSERT_TEXT` может уйти в несколько диспетчеров.
2. Кнопка бинда невидима (`opacity:0`), но кликается и «плавает» после названия; режим записи съедает
   набор в поиске.
3. Если проект не определён, вкладка «Все» → Alt+1 вставляет первый закреплённый — шаблон РО на Мадже.

## Решения

- Две версии на выбор: BetterDiscord (закинуть файл) и Vencord (сборка из исходников, свой
  установщик). Общее ядро, тонкие обёртки.
- Vencord не грузит плагины из папки — только userplugins + пересборка. Проверено: спайк собран,
  `pnpm inject` в Discord Stable.
- Стиль — как панель Majestic (палитра `.dark`, Golos Text, малиновый акцент, янтарные линии).
  Проекты — иконками в одинаковых квадратах (фавикон Majestic, логотип-ушанка РО), не цветом:
  фирменные `#d00457` и `#c23533` слишком близки.
- Концепт из 4 состояний: А — `;команда` в строке ввода; Б — окно (Избранное, Недавние, категории,
  текст справа); В — защита (устаревшие шаблоны, поля); Г — личные шаблоны.
- Проект по guild ID: Majestic RP `530693013622489088`, Россия Онлайн `1089530150540034181`;
  чужие шаблоны скрыты, выбор чужого → зеркальный шаблон по названию.
- Только ru/ro (без EU), авто-отправку из панели игнорировать, счётчик в панель не писать,
  обновления плагина раздаёт панель.
- Сервер (вход плагина как устройства через Discord OAuth, API шаблонов) пишет разработчик панели
  по ТЗ; Discord-токен пользователя в панель не уходит никогда.

## Что уже есть в панели (снято GET-запросами)

- FAQ (`/api/faq`): командные шаблоны — категории, статус `actual/needs_review/outdated`,
  `usage_count` по команде, маркер `[[greeting:end]]`; на странице — избранное, недавние,
  предложения правок, история версий.
- Личные шаблоны (`/api/templates`): имя, текст, команда, цвет, папка, `shared`; папки с доменами;
  корзина 7 дней; токены `{|}`, `{{поле}}`, `{{поле=деф}}`, `{{поле|a|b}}`, `{{date±N[mhdw]}}`,
  `{{time}}`, `{{clipboard}}`, `{{selection}}`, `{{url}}`, `{{title}}`.
- Браузерное расширение «Majestic Templates» с устройствами (`/api/ext/devices`, отзыв), в его
  списке сайтов есть `discord.com`.
