C · Палитра по центру, предпросмотр по требованию

Как Ctrl+K в Discord: по центру экрана, крупный поиск. По умолчанию узкий список (быстро), стрелка → или кнопка выдвигает панель полного текста справа и запоминает выбор. Быстрым — без лишнего, сомневающимся — включил раз и работает.
