# SupportTemplates · сборка 18

Три варианта: BetterDiscord, полный Vencord с другими плагинами, отдельная сборка только с SupportTemplates.

- Исправлена вставка шаблонов BetterDiscord: событие Discord теперь получает `rawText` и `plainText`, как рабочая реализация Vencord. Отправки сообщений нет.
- В настройках явно указан вариант установки и номер сборки. Техническая версия для API и обновлений остаётся `1.0.1-canary.18`.
- Размер настроек одинаковый во всех разделах; содержимое прокручивается внутри.
- Список и настройки остаются открытыми при выделении текста и вводе в чат. Закрытие — крестиком/кнопкой или Escape внутри окна; защита несохранённого шаблона сохранена.
- Окно списка можно растягивать за верхний левый угол. Размер запоминается локально, ограничивается размерами экрана. На ручке работают стрелки, Shift увеличивает шаг.

BetterDiscord: замените `SupportTemplates.plugin.js`, оставив один экземпляр, затем выключите и включите плагин. Версия сохраняет поддержку входа и обновлений .16/.17. Для двух сборок Vencord инструкция находится внутри ZIP; установщик BAT/PowerShell, без EXE.

Репозиторий пока приватный: для скачивания нужен доступ к нему; анонимная доставка обновлений сотрудникам заработает после открытия репозитория владельцем. Изменения проверены тестами и браузерным стендом; живую вставку в Discord должен подтвердить владелец.
