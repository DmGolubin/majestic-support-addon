# SupportTemplates 1.0.1-canary.24

All three Windows variants use the same SupportTemplates version. This release
fixes full Vencord's QuickCSS dependency gate; existing SupportTemplates features
remain unchanged.

- QuickCSS uses pinned Monaco 0.57.0 and DOMPurify 3.4.17. The builder replaces
  Monaco's vendored sanitizer as well as resolving package imports to the pin.
- The editor, styles, font and CSS workers are included in the package. Opening
  QuickCSS does not fetch executable code from a CDN.
- A small data-URL document preserves Vencord's isolated preload routing and
  stays below Electron's URL limit. The main process executes only the packaged
  editor script after navigation. User CSS remains data passed through the bridge.
- CSP denies document scripts and network connections; workers use bundled blob
  URLs. Worker shutdown/recycling and the visible load-failure state are handled.
- The full Vencord plugin inventory is preserved. BetterDiscord and the reduced
  standalone variant do not include the QuickCSS editor.

Source, dependency pinning and package checks are recorded in the Q19 audit.
Installation into actual Discord and live account acceptance are separate from
local fixture verification. No release is published by the build command.
