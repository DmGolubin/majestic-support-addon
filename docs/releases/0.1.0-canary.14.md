# SupportTemplates 0.1.0-canary.14

Тестовый выпуск для Windows. Три варианта с общей библиотекой шаблонов и обновлением через GitHub Releases:

| Вариант | Что скачать |
|---|---|
| BetterDiscord | `SupportTemplates.plugin.js` для уже установленного BetterDiscord; ZIP дополнительно содержит исходники и лицензию |
| Vencord со стандартными плагинами и SupportTemplates | `SupportTemplates-vencord-0.1.0-canary.14.zip` |
| Отдельная сборка только с SupportTemplates | `SupportTemplates-standalone-0.1.0-canary.14.zip` |

ZIP нужно распаковать целиком, закрыть целевой Discord через трей и запустить `install.bat`. Установщики на BAT/PowerShell, без EXE. По умолчанию выбран Canary. Один клиент Discord — один вариант установки.

В комплект входят инструкция `INSTALL-RU.md`, исходники, сведения о сборке, `SHA256SUMS.txt` и манифест обновлений. Версия собрана из `d3ab8bc76a55e163d7189b6a71a45bb5661c8387` на закреплённом Vencord `32c90633ce6a95d7e56c95479efbb431bacf1eac`.

Обновлятор проверяет выпуски при запуске и примерно каждые шесть часов. Скачанный пакет проверяется по размеру и SHA-256; Discord принудительно не закрывается. Обновления применяются при следующем запуске. Пока репозиторий приватный, автоматическая анонимная загрузка недоступна; скачать этот выпуск могут пользователи с доступом к репозиторию. После перевода репозитория в публичный дополнительные GitHub-токены сотрудникам не нужны. Для следующего обновления нужен новый Release с пакетами и манифестом, одного push недостаточно.

Проверки: 1584 Vitest-теста, обе проверки типов, 12 Node-тестов Vencord distribution и проверки установщиков на временных файловых стендах прошли. Все девять файлов выпуска прошли проверку контрольных сумм. Отдельная `.14` установлена в Canary владельца, Status подтвердил версию, клиент запущен.

Живая приёмка интерфейса, API и звука на `.14` ещё не завершена. BetterDiscord и полный Vencord требуют отдельной проверки в реальных клиентах. Доставка обновления из публичного GitHub пока не проверена. Выпуск не объявляется готовым стабильным MVP; подробности — в `docs/audits/2026-10-19-three-distributions.md` и текущем roadmap.

Для короткой проверки отдельной сборки: открыть шаблоны и настройки, проверить вход и загрузку FAQ, создать/изменить личный шаблон, вставить его в редактор без отправки, проверить свой звук, затем сохранить черновики и проверить Ctrl+R и полный перезапуск.
