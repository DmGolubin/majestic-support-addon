# SupportTemplates .16 — вход и обновления BetterDiscord

Выпуск только для BetterDiscord. Полный Vencord и отдельная сборка остаются на `.14`.

- Вход сохраняется после Ctrl+R и полного перезапуска Discord. Сессия зашифрована в профиле; выход удаляет сохранённые данные.
- Плагин проверяет GitHub при запуске и каждые шесть часов. Новая версия загружается в отдельный кэш и включается после Ctrl+R, следующего запуска или выключения/включения плагина.
- Загрузка не перезапускает интерфейс. Проверяются источник, канал canary, версия, размер и SHA-256. При ошибке остаётся встроенная версия.

## Один раз установить .16

1. Сохраните открытые черновики и отключите SupportTemplates в BetterDiscord.
2. Перенесите прежний `SupportTemplatesDEV.plugin.js` или `SupportTemplates.plugin.js` из plugins в резервную папку.
3. Положите новый `SupportTemplates.plugin.js` в plugins, включите и один раз войдите через сайт.
4. Нажмите Ctrl+R и откройте шаблоны: библиотека должна восстановиться без нового подтверждения на сайте. Проверьте также полный перезапуск Discord.
5. Нажмите «Выйти», перезапустите: вход не должен восстановиться сам.

Очистка данных профиля Discord, отзыв доступа на сервере или незавершённая ротация токена могут потребовать нового входа. Шифрование в профиле не равно системному хранилищу ключей: доверенные плагины в том же профиле имеют доступ к его окружению.

**Пока `skyjacc/support-templates` приватный, анонимное скачивание обновлений недоступно.** После открытия репозитория опубликованные выпуски с манифестом будут доступны обновлятору. GitHub-токены сотрудников не нужны. Для живой проверки доставки потребуется следующий выпуск новее `.16`.

Проверки на стенде описаны в `docs/audits/2026-10-19-betterdiscord-persistence-updates.md`. Проверка настоящего BetterDiscord остаётся приёмкой пользователя.
