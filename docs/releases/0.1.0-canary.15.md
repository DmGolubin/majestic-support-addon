# SupportTemplates .15 — исправление BetterDiscord

Выпуск содержит только BetterDiscord-плагин. Полный Vencord и отдельная сборка `.14` не заменяются.

Исправлена ошибка загрузки `ENOENT ... node:https`: BetterDiscord предоставляет ограниченный набор модулей, а плагин ошибочно рассчитывал на полный Node.js. Запросы панели переведены на потоковый `BdApi.Net.fetch`; `node:*` больше не передаётся загрузчику BD, необязательные native-модули загружаются только при наличии необходимых функций хоста.

## Установка

1. Отключите старый SupportTemplates в BetterDiscord.
2. Перенесите старый `SupportTemplatesDEV.plugin.js` (или прежний `SupportTemplates.plugin.js`) из папки plugins в резервную папку. Не оставляйте две копии плагина одновременно.
3. Скачайте `SupportTemplates.plugin.js` из этого выпуска, положите в plugins и включите.

Сам BetterDiscord должен быть установлен. Другие его плагины менять не нужно.

## Ограничения

В стандартном BetterDiscord вход действует только до перезапуска Discord. Сохранение токена открытым текстом не используется. Автообновление нашего файла также пока недоступно: хост не предоставляет необходимые атомарные операции файлов и блокировок. Настройки явно предлагают обновлять плагин вручную. Эти ограничения сохраняются и после открытия репозитория.

Ошибка воспроизведена на старом итоговом файле, новый проходит загрузку и открытие настроек с ограниченным require. 1586 тестов / 72 файла и проверка типов прошли; сетевые тесты проверяют потоковый ответ, отмену, запрет перенаправлений и сохранение HTTP-ошибок API. Проверка живого BetterDiscord у пользователя остаётся необходимой.
