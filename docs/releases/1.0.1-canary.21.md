# SupportTemplates 1.0.1-canary.21 — локальные пакеты

Все три варианта собраны в `artifacts/distribution/1.0.1-canary.21/`:

- `SupportTemplates.plugin.js` — плагин для установленного BetterDiscord.
- `SupportTemplates-vencord-1.0.1-canary.21.zip` — полный Vencord со штатными плагинами и SupportTemplates.
- `SupportTemplates-standalone-1.0.1-canary.21.zip` — основа Vencord с одним пользовательским плагином SupportTemplates и необходимыми внутренними модулями.

Оба ZIP используют BAT/PowerShell, отдельного EXE-установщика нет. Комплект содержит
исходники, лицензии, контрольные суммы и общий манифест обновлений. Это локальный
комплект: публикации на GitHub и установки в Discord в рамках этой задачи не было.

## Что вошло

- Включаемая файловая диагностика: действия, запросы к панели, HTTP-статусы,
  обновление входа, сетевые отказы и известные причины завершения сессии.
- Сохранение журнала после Ctrl+R и экспорт в JSON без токенов, заголовков,
  тел ответов, текстов сообщений и шаблонов.
- Ограничение журнала: последние 2000 событий, компактное хранилище до 512 КиБ,
  автоматическое выключение записи через 24 часа.
- Исправления жизненного цикла и лишней нагрузки из .20.
- Для BetterDiscord — компактная служебная страница вместо второй копии редактора.

## Проверка в настоящем клиенте

1. Установите выбранный вариант по `INSTALL-RU.md` и README пакета. Один мод на один
   клиент Discord. Для установки Vencord/отдельной сборки полностью закройте целевой
   клиент и распакуйте ZIP до запуска `install.bat`.
2. Откройте SupportTemplates, проверьте версию .21, библиотеку и вставку шаблона
   в поле сообщения без отправки.
3. В настройках включите **«Записывать диагностику на 24 часа»**, откройте и закройте
   несколько окон, затем перезагрузите Discord через Ctrl+R. Запись должна остаться включённой.
4. Нажмите **«Скачать диагностику»**: должен сохраниться JSON с версией .21 и историей.
   После реального сбоя скачайте его сразу и приложите время и описание проблемы.

Пакетные и изолированные проверки описаны в
[отчёте](../audits/2026-10-19-distributions-21.md). Живая приёмка клиента и доставка
обновления из публичного GitHub ещё не проверены. Репозиторий остаётся приватным.
