# SupportTemplates 1.0.1-canary.17 — исправление подключения BetterDiscord

Исправлен ложный отказ «Для подключения нужна новая версия плагина» в сборке `.16`.

Причины: проверка принимала только x.y.z и отвергала canary; при упаковке версия клиента 1.0.0 ошибочно заменялась на 0.1.0-canary.N, ниже минимума 1.0.0 из поставленного контракта API. Новая версия 1.0.1-canary.17 выравнивает нумерацию. Сравнение учитывает prerelease и build metadata по SemVer; требование сервера не отключено. Более новый минимум всё ещё блокирует несовместимый клиент.

Сохранение входа и загрузка обновлений из `.16` остаются. В тесте итоговый плагин с ограниченным require BetterDiscord восстановил зашифрованный вход и показал FAQ при minimumPluginVersion=1.0.0 без повторной авторизации.

## Установка и проверка

1. Отключите SupportTemplates, замените файл `SupportTemplates.plugin.js` и включите снова. Оставьте только одну копию в plugins; прежний DEV-файл уберите в резервную папку вне plugins.
2. Если прежняя попытка подключения отозвала сессию после ошибки версии, один раз войдите через сайт.
3. Откройте FAQ, затем нажмите Ctrl+R и проверьте, что библиотека восстановилась без сайта. Повторите после полного перезапуска Discord.

Репозиторий пока приватный, поэтому этот файл нужно поставить вручную. Анонимные обновления GitHub станут доступны после открытия репозитория. Запросы BdApi.Net выполняются через native-модуль и могут отсутствовать в Network DevTools окна Discord.

Выпуск только для BetterDiscord. Установленные Vencord и отдельная сборка `.14` не изменены. Живая приёмка у пользователя остаётся необходимой; текущий минимум живого API не был прочитан, проверка использует поставленный контракт.
