# SupportTemplates 1.0.1-canary.22

MVP polish for BetterDiscord, Vencord and the reduced Vencord-based distribution.
No new product features.

- Login confirmation opens `https://panel.majestic-rp.tech/connect?code=…` directly,
  including when the API supplies a legacy link or omits the complete URL.
- Temporary transport failures preserve the panel session and retry with backoff.
  Server Retry-After is respected even when another event supersedes a request.
- Bursts of library events share a resync. Reminder settings and polling no longer
  bypass retry delays under repeated synchronization or invalidation.
- Closing the picker returns focus to its opener. Unsaved-change confirmation
  focuses the safe return action; Escape returns to the draft without discarding it.
- Long form errors wrap inside the window; IME composition does not trigger login
  dialog shortcuts.

Existing file diagnostics remain available in all three variants.
Actual account revocation and an uncertain refresh-token rotation still require
reauthorization. Website OAuth and upstream availability remain server concerns.
