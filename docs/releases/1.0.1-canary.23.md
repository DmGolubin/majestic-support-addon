# SupportTemplates 1.0.1-canary.23

Full own-code audit and fixes for BetterDiscord, Vencord and the reduced
Vencord-based distribution. No new product features.

- Failed reminder-settings reads use bounded backoff, and repeated resume events
  no longer repeatedly replace a fresh panel event stream.
- Greeting parsing stays linear on long whitespace input. Invalid import rows
  and usage metadata no longer discard surrounding valid data. Historical backup
  aliases and saved references retain their intended identity.
- Repaired storage writes are serialized with subsequent user changes. Repeated
  saved references are deduplicated; unrelated empty normalized titles cannot
  substitute a template from another project.
- Older asynchronous insertion attempts cannot replace newer choices. Held Enter
  is consumed before focus returns to the composer; global shortcuts ignore IME
  composition and AltGr.
- BetterDiscord clipboard errors propagate correctly, partially registered Flux
  listeners are cleaned up, and updater recovery survives corrupt pending state
  or an incompatible cached renderer.
- The native Windows DPAPI fallback runs asynchronously, keeping the event loop
  responsive during protected storage operations. One bounded child performs the
  availability probe; the existing encrypted storage format is retained.
- Native update cancellation, helper-lock recovery and renderer-only package
  compatibility checks are corrected. Configuration validation agrees between
  builders and the shipped updater.
- Vencord and standalone native plugin settings now show connection state,
  diagnostics and an explicit handoff to the main SupportTemplates window.
  They no longer embed another full template editor.

The direct panel connect URL and bounded, opt-in file diagnostics from previous
builds remain available in all three variants.

These are local review candidates, not a production approval. In particular,
full Vencord's upstream QuickCSS editor fetches Monaco 0.50.0 containing
DOMPurify 3.0.5. That external component has published vulnerabilities and is
not repaired by this own-code release. Do not mass-release the full Vencord
candidate until that dependency and actual client acceptance are resolved.
The reduced distribution and BetterDiscord do not include this QuickCSS path.
