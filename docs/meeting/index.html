Показ за 5–7 минут

  1. Вход. Открыть меню в Discord, подтвердить код на локальной панели, дождаться списка.
  2. Быстрый ответ. Показать поиск, Shift и вставку в свой черновик.
  3. Мои шаблоны. Создать папку и цветной ответ с полем имени, вызвать по команде.
  4. Обновление FAQ. Изменить текст на странице подтверждения и увидеть новую версию в плагине.
  5. Что дальше. Открыть roadmap: API, приёмка, тикеты, BetterDiscord.

Границы демонстрации

Вход и обновления FAQ работают на локальном демосервере. Настоящий API панели ещё не подключён. Личные шаблоны в демо временные; двусторонней синхронизации нет. Основные FAQ через приложение менять нельзя — обновление показываем со стороны тестового сайта.

Звуки тикетов, таймер ответа, статистика и BetterDiscord — в плане. Плагин не отправляет сообщения автоматически.
