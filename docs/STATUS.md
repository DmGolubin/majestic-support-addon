## Принятые решения

- Только Majestic, Россия Онлайн и Tech; остальные серверы и ЛС выключены.
- Плагин вставляет текст, не отправляет сообщения и не забирает тикеты.
- Основные FAQ редактируются на сайте; токен плагина — только чтение.
- Личные шаблоны редактируются в плагине с записью на панель. Реализуем C06 по полученному контракту; права записи подтверждаются отдельно, FAQ остаётся только для чтения.
- Без emoji в интерфейсе. EU и автоотправка исключены. Отдельный EXE не требуется.
- Бинды, недавние, частота использования и избранное в v1 локальные; счётчик использования на панель не отправляем.
- Две публичные поставки: SupportTemplates Lite (на основе Vencord, только наш плагин) и SupportTemplates для BetterDiscord. Полный Vencord + SupportTemplates остаётся личной сборкой владельца. Общая кодовая база UI/ядра, последовательная проверка общего UI, Lite, BetterDiscord.
- Контракт Дмитрия: порог личного напоминания берётся из Telegram и меняется там; плагин меняет только discordEnabled. Системные 20/30 не меняются.
- Рабочая библиотека — аккаунт панели. Импорт, локальная библиотека и демопереключатель подлежат удалению из обычного интерфейса (A18); старые локальные данные не удаляем молча. Q01 про импорт снят с плана.
