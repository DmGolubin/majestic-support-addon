# SupportTemplates Lite

## Установка

Распакуйте ZIP целиком. Внешний каталог содержит только:

```text
SupportTemplates-<версия>/
  install.bat
  uninstall.bat
  SupportTemplates/
```

Запустите `install.bat`: откроется консольное меню с ASCII-оформлением. Выберите Discord Stable или Canary, затем нужное действие: установить, проверить обновления, показать статус, восстановить подключение или удалить. Перед установкой полностью выйдите из выбранного Discord через трей. Установщик не закрывает процессы и не заменяет чужие Vencord/BetterDiscord.

В начале проверяется доступность новой версии. Загрузка выполняется по команде пользователя; пакет проверяется по версии, размеру, SHA-256 и безопасной структуре ZIP. Следующая установка использует проверенную загруженную версию. Ошибка сети не мешает установить имеющийся пакет.

В папке `SupportTemplates/` находятся служебные скрипты, `payload/`, манифест, лицензия и соответствующие исходники Vencord. Для работы BAT нужна эта папка рядом. PowerShell 5.1 используется для операций с файлами и проверок; графического окна WPF нет.

`uninstall.bat` удаляет подключение Lite, сохраняя настройки. Восстановление после обновления Discord доступно в меню установки.

## Версии и обновления

Версия и источник обновлений задаются в `distribution/config.json`. Для анонимной загрузки репозиторий GitHub должен быть публичным. GitHub-токен сотрудника не требуется.

**Переход с 1.0.1:** один раз скачайте новый компактный архив вручную. Обновлятор 1.0.1 рассчитан на прежнюю структуру пакета. Начиная с 1.0.2 поддерживаются обе структуры; последующие пакеты можно получать через меню BAT.

Плагин также проверяет опубликованные релизы при запуске и примерно раз в шесть часов. Загрузка не закрывает Discord. Полное обновление Lite устанавливается после выхода из выбранного клиента. Новый Discord запускайте после завершения установки.

## Консольные параметры

`install.bat -Channel Stable` и `install.bat -Channel Canary` устанавливают текущий распакованный пакет без сетевой проверки. `-WhatIf` показывает план без записи. PTB и переносимые установки не поддерживаются.

Для служебных операций доступен `SupportTemplates/SupportTemplates.ps1` с `-Action Status`, `Repair`, `Rollback`, `Uninstall` или `UpdateRenderer` и явным `-Channel`. `UpdateRenderer` подходит только для совместимых изменений интерфейса; изменения загрузчика или native требуют полной установки после выхода из Discord.

## Данные и логи

Данные лежат в `%LOCALAPPDATA%/SupportTemplates/channels/<клиент>/`. Слово `canary` здесь обозначает Discord Canary, а не тестовую версию плагина. Настройки и зашифрованный вход сохраняются при обновлении и удалении подключения.

В настройках плагина раздел «Логи» открывает папку с `main.log`. Журнал дописывается между запусками; сохраняются текущий файл и до девяти архивов по 10 МиБ. Запись можно отключить. Тексты сообщений, шаблонов, токены и тела запросов не записываются. Автоматической отправки нет.

Манифест и SHA-256 проверяют целостность, а не являются отдельной цифровой подписью. Источник обновлений — опубликованные релизы выбранного GitHub-репозитория по HTTPS.
